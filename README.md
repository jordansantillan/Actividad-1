# Sistema de Control de Rescate y Adopción

Prototipo estructural del sistema de gestión de un refugio de animales,
desarrollado con HTML5 semántico para la asignatura de Desarrollo de
Sistemas Informáticos.

## Páginas

| Archivo | Descripción |
|---|---|
| `index.html` | Dashboard con bienvenida y resumen del refugio |
| `reportar.html` | Formulario para registrar un animal rescatado |
| `rescates.html` | Tabla con el listado de casos registrados |

## Estructura

    ├── assets/
    │   └── img/
    ├── index.html
    ├── reportar.html
    └── rescates.html
